# Alma Animal

Landing page estática para un concepto de clínica veterinaria integral. Presenta medicina preventiva, consulta, diagnóstico, cirugía, hospitalización, urgencias, baño, estética, tienda y un formulario de reserva que prepara un mensaje de WhatsApp.

## Tecnología

- HTML semántico
- CSS responsive con tipografías locales
- JavaScript vanilla
- Sin framework, base de datos ni backend

## Ejecutar localmente

Abre `index.html` directamente o inicia un servidor estático:

```bash
python -m http.server 4173
```

Después visita `http://127.0.0.1:4173/`.

## Contacto configurado

El formulario abre WhatsApp al número `+51 934 181 908`. La página no almacena los datos introducidos.

## Nota

Alma Animal es un concepto demostrativo. Los horarios, disponibilidad, protocolos y servicios deben confirmarse directamente con la clínica antes de usarse en producción.
